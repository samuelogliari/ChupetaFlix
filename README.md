---- CHUPETAFLIX ----
Projeto
ChupetaFlix;

Tema
Gerenciamento de Mídia de streaming;

Descrição
O projeto tem como objetivo ser funcional conjuntamente com o banco de dados, trazendo a possibilidade de criação, atualização, verificação e exclusão de cadastros de Animes, Filmes, Atores e Séries.
O qual será desenvolvido em Java, utilizando PostgreSQL como banco de dados e JDBC para garantir a comunicação entre a aplicação e o banco.

Utilizando
Para funcionar, é necessário que seja configurado o banco de dados (o qual temos uma cópia na ChupetaFlix.sql), e executar a aplicação do Java.
Funcionalidades principais previstas:
* Cadastro de animes, filmes, atores e séries;
* Consulta de registros;
* Atualização de cadastros;
* Exclusão de Registros;
* Associação de atores aos filmes;
